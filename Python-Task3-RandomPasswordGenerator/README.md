# Random Password Generator 🔐

A Python-based Random Password Generator developed as part of the **Oasis Infobyte Python Programming Internship – Task 3**.

## 📌 Project Description

This project generates strong random passwords based on the user's selected requirements.

The user can choose:
- Password length
- Uppercase letters
- Lowercase letters
- Numbers
- Symbols

The program also validates user input and allows generating multiple passwords without restarting.

## ✨ Features

1. 🔢 Custom password length
2. 🔠 Uppercase letters
3. 🔡 Lowercase letters
4. 🔢 Numbers
5. 🔣 Symbols
6. ✅ Minimum password length of 8 characters
7. ✅ At least 2 character types required
8. ⚠️ Input validation
9. 🔄 Generate multiple passwords
10. 🚪 Exit option
