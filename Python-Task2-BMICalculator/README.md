# BMI Calculator

## Oasis Infobyte Internship – Python Programming

This project is a simple **BMI (Body Mass Index) Calculator** developed using Python as part of the Oasis Infobyte Python Programming Internship.

## Features

- Accepts weight in kilograms.
- Accepts height in meters.
- Calculates BMI using the standard formula.
- Displays the BMI value.
- Displays the corresponding BMI category.

## BMI Formula

BMI is calculated using:

BMI = Weight (kg) / Height² (m)

## BMI Categories

| BMI Range | Category |
|---|---|
| Below 18.5 | Underweight |
| 18.5 – 24.9 | Normal Weight |
| 25.0 – 29.9 | Overweight |
| 30.0 and above | Obesity |

## Example

Input:

- Weight: 50 kg
- Height: 1.60 m

Output:

```text
Your BMI: 19.53
Category: Normal Weight```
