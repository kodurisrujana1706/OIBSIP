# BMI Calculator

A simple Python-based BMI Calculator that calculates Body Mass Index using a person's weight and height.

## Features

- Accepts weight in kilograms.
- Accepts height in meters.
- Calculates BMI.
- Displays BMI up to two decimal places.
- Classifies BMI as Underweight, Normal Weight, Overweight, or Obese.
- Handles invalid and non-numeric input.
- Rejects negative or zero values.

## How to Run

1. Make sure Python is installed.
2. Open the project in VS Code.
3. Run `bmi_calculator.py`.
4. Enter your weight in kilograms.
5. Enter your height in meters.
6. The program displays your BMI and category.

## Example

```text
Enter your weight in kg: 50
Enter your height in meters: 1.60

Your BMI: 19.53
Category: Normal Weight
```
